
# ALU Webstack

This repository contains my ALU Webstack projects and assignments focused on system engineering, DevOps, web servers, load balancing, and HTTPS configuration.

## Project: HTTPS and SSL

Directory: `https_ssl`

This project covers:

### Task 0: World Wide Web
- Configure DNS records for domain subdomains.
- Create a Bash script to display DNS information.

### Task 1: HAProxy SSL Termination
- Generate an SSL certificate using Certbot.
- Configure HAProxy to accept HTTPS traffic on port 443.
- Forward encrypted website traffic to web servers.

### Task 2: Redirect HTTP to HTTPS
- Configure HAProxy to redirect HTTP requests to HTTPS.
- Use HTTP status code 301.

## Requirements

- Ubuntu/Linux
- Bash
- HAProxy 1.5 or higher
- Certbot
- DNS configuration access
